# Industrie 4.0 AR Mockup

Contains a simple template for starting with an AR featured Web-APP using AFrame and AR.js.

## Grober Projektplan (LF 7: Cyber-physische Systeme ergänzen)

### 1. Informieren & Analysieren
- Analyse Produktionsanlage
- Ermittlung Datenfluss
- Anforderungsanalyse

### 2. Planen & Konzipieren
- Schnittstellen
- Netzwerk-Architektur
- Sicherheitskonzept?

### 3. Entscheiden & Begründen
- Datenübertragungsstandard
- Visualisierung
- Festlegen Demodaten

### 4. Durchführung
- Erstellung Diagramm
- Schriftliches Architekturkonzept
- Erstellung Mockup

### 5. Prüfen / Testen
- Soll-Ist-Vergleich
- Check Sensorwerte
- Iteration / Diskussion Ergebnisse

### 6. Bewerten / Präsentation
- Ausarbeitung Pitch
- Fazit
